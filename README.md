## Projects

<details>
<summary><b>⚡ FlowSync — Event-Driven Workflow Automation Platform</b></summary>
<br/>

A production-grade backend built to deeply learn distributed systems, async processing, and real-time infrastructure. Every architectural decision is intentional.

| Layer | Tech |
|---|---|
| API | Express.js + TypeScript |
| Database | PostgreSQL |
| Cache & Queue | Redis + BullMQ |
| Real-time | WebSockets |
| Infra | Docker + Nginx |
| Observability | Prometheus + Grafana |

**Why it exists:** Teams need reliable, auditable automation for event-triggered workflows — webhook fan-out, scheduled jobs, retry logic with dead-letter queues, and live status updates. FlowSync is the self-hostable backend engine that powers all of it.
